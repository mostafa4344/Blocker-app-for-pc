How to install

Takes about 2 minutes. Works on Windows 10 and 11.

1

Download

Click the download button for the app (above / on the product page), or run the one-line installer in PowerShell. Save the file somewhere you can find it, like your Downloads folder.

2

Run the installer needs Administrator

Right-click the downloaded file → Run as administrator. (The app installs a background service that does the blocking, so it needs admin rights once, during install.)

3

If Windows shows a blue “Windows protected your PC” box

This is normal for a new app that is not code-signed yet — it does not mean the app is unsafe. Just click More info, then click Run anyway.

Windows protected your PC
Microsoft Defender SmartScreen prevented an unrecognized app from starting…
→ Click More info → then the Run anyway button that appears.

We are adding a verified publisher signature soon, after which this message will no longer appear.

4

Open the app

When install finishes, the app opens in your browser at http://127.0.0.1:17345. Set your language and blocking in a minute of onboarding.

5

Add the browser extension (recommended)

For keyword blocking and hiding Shorts / Reels / feeds, install the free HTL Content Guard PC extension from the Chrome Web Store, or turn on Settings → Browser protection → “Lock the extension into my browsers” to install it automatically and lock it so it can’t be removed.

One-line installer (optional)

Open PowerShell and paste this (it downloads and installs for you):

irm 'https://raw.githubusercontent.com/mostafa4344/Blocker-app-for-pc/ccr-00759c63-vxxesd/packaging/windows/install-online.ps1' | iex

If PowerShell shows a security prompt, press R (Run once) or type Y and Enter.

Trouble?

If your antivirus flags the app, choose Allow / Keep — it is a false positive common to new, unsigned apps and goes away once the app is signed and trusted. For help, contact support at halaltechlife.com.
