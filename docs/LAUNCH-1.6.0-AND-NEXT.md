# HTL Content Guard PC — 1.6.0 লঞ্চ অবস্থা ও পরের কাজের তালিকা

(৩০ অক্টোবর ২০২৬)

## ✅ যা তৈরি ও চালু

| কী | কোথায় | অবস্থা |
|---|---|---|
| Windows installer 1.6.0 | `dist/HTL-Content-Guard-PC-Setup.exe` (2.6 MB) | তৈরি, আপনার PC-তে বসিয়ে যাচাই করা |
| আপডেট সার্ভার | Supabase storage `releases/v1.6.0/` + টেবিল `app_releases` (rollout 100%) | প্রকাশিত, অনলাইনের ফাইল মিলিয়ে দেখা (SHA-256 এক) |

| ব্রাউজার এক্সটেনশন 1.1.0 | `dist/content-guard-extension.zip` | তৈরি — **Chrome Web Store-এ আপলোড বাকি** |
| লাইসেন্স সুরক্ষা | সার্ভারে সই করা লাইসেন্স + প্রতিটা PC-তে বাঁধা | চালু, PC-তে যাচাই করা |

> Android-এর APK এই প্রজেক্টে নেই: এটা Windows PC-র অ্যাপ। ইনস্টল ফাইল হলো উপরের `.exe`।

### এই দফায় ঠিক করা
- লাইভ সার্ভারে খোলা থাকা পরীক্ষার কোড (PREMIUM-LIFETIME ইত্যাদি) মুছে ফেলা।
- Premium শুধু সার্ভারের সই করা লাইসেন্স থেকে; লাইসেন্স ফাইল বদলে বা অন্য PC-তে কপি করে Premium পাওয়া যায় না।
- সাধারণ (অ্যাডমিন নয়) Windows ইউজার অ্যাপের ফোল্ডারে আর কিছু লিখতে পারে না।
- ওয়েবসাইটের "Get Premium" ফর্ম এখন অ্যাপের মতোই নিরাপদ পথে জমা হয়; দাম সরাসরি Supabase-এর `plans` টেবিল থেকে আসে (আগে ওয়েবসাইটে ভুল দাম ও "Lifetime" দেখাত)।
- FAQ-তে এক্সটেনশন কোন ব্রাউজারে নিজে বসে, তা ঠিক করা।

## 👤 আপনার করণীয় (আমি করতে পারি না — আপনার অ্যাকাউন্ট লাগে)

1. **GitHub রিপো প্রাইভেট করুন** — সবচেয়ে জরুরি। পাবলিক থাকলে যে কেউ কোড নামিয়ে লাইসেন্স-চেক ছাড়া নিজে বানাতে পারে।
   GitHub → Blocker-app-for-pc → Settings → General → নিচে "Change repository visibility" → Private।
2. **ওয়েবসাইট আপলোড:** `dist/website-upload.zip` খুলে ভেতরের `content-guard-pc` ফোল্ডারের সব ফাইল আগের জায়গায় বসান (পুরনোগুলো বদলে দিন)। গাইড: `WEBSITE-UPLOAD-GUIDE.html`।
3. **এক্সটেনশন 1.1.0 Chrome Web Store-এ:** Developer Dashboard → HTL Content Guard PC → Package → Upload new package → `dist/content-guard-extension.zip` → Submit for review। (এটা হলে Chrome-Edge একসাথে খোলা থাকলেও কোনটায় এক্সটেনশন আছে অ্যাপ ঠিক বুঝবে।)
4. **Edge Add-ons আর Firefox AMO-তে প্রকাশ** (বিনামূল্যে) এবং আইডিগুলো আমাকে দিন — তাহলে Edge/Firefox-এও এক্সটেনশন নিজে বসবে।
5. **গোপন চাবিগুলোর ব্যাকআপ:** `C:\Users\user\HTL-Signing\` ফোল্ডারটা USB/নিরাপদ জায়গায় কপি রাখুন। এটা হারালে আর আপডেট পাঠানো যাবে না।
6. **Supabase-এর লাইসেন্স চাবি** (`Vault → license_signing_seed`) কখনো মুছবেন বা বদলাবেন না — বদলালে সবার Premium বন্ধ হয়ে যাবে।

## 🛠️ সাপোর্টে কাজে লাগবে
- **"এই ডিভাইস আইডি আরেকটা কম্পিউটারের সাথে যুক্ত"** — ক্রেতা Windows বা অ্যাপ নতুন করে বসালে। Supabase → Table Editor → `accounts` → তার Device ID-র সারিতে `device_key` ঘর খালি করে Save। কয়েক মিনিটে নতুন PC-তে Premium চলবে।
- **টাকা পাঠানোর অনুরোধ অনুমোদন:** Table Editor → `purchase_requests` → bKash/Nagad অ্যাপে TrxID মিলিয়ে `status` = approved।
- **দাম বদলানো:** Table Editor → `plans` (অ্যাপ আর ওয়েবসাইট দুই জায়গায় একসাথে বদলায়)।
- **নতুন ভার্সন ছাড়া:** আমাকে বললেই build → সই → আপলোড → `app_releases`। সমস্যা হলে `app_releases`-এ সেই ভার্সনের `enabled` = false।

## 🔜 পরের আপডেটগুলোর তালিকা (গুরুত্ব অনুযায়ী)

### ১. লঞ্চের সাথে সাথে / জরুরি
1. **Code-signing সার্টিফিকেট** (টাকা হাতে এলে) — নীল "Windows protected your PC" বার্তা আর অ্যান্টিভাইরাসের ভুল সতর্কতা কমবে; ডাউনলোড-বিশ্বাস অনেক বাড়বে।
2. **Microsoft-এ ফাইল জমা** (Defender false-positive submission) — সার্টিফিকেট ছাড়াও অ্যান্টিভাইরাস সতর্কতা কমায়।
3. **বড় ডাউনলোডের জন্য GitHub Releases / CDN** — Supabase storage-এ লাখো ডাউনলোড ব্যয়বহুল; installer অন্য জায়গা থেকে দেওয়া (আপডেটের সই একই থাকবে)।
4. **কার্ড/PayPal পেমেন্ট (Paddle)** — বিদেশি ক্রেতাদের জন্য; কোড তৈরি আছে, শুধু অ্যাকাউন্ট ও কী বসানো বাকি।

### ২. ফাঁক বন্ধ / আরও শক্ত ব্লক
5. **সিস্টেম-জুড়ে DNS ফিল্টার (Windows Filtering Platform)** — এক্সটেনশন ছাড়াই সব ব্রাউজার ও অ্যাপে নিরাপদ ফিল্টার; VPN/প্রক্সি দিয়ে এড়ানো কঠিন হবে।
6. **VPN/প্রক্সি অ্যাপ চেনা** — ব্লক চলার সময় পরিচিত VPN অ্যাপ সতর্ক করে বন্ধ (সুরক্ষা-সুইচের অধীনে)।
7. **সেটিংস ফাইলের সই (HMAC)** — অ্যাডমিন সার্ভিস বন্ধ করে ফাইল বদলালেও ধরা পড়বে।
8. **লাইসেন্স শেয়ারিং ধরা** — একই অ্যাকাউন্ট অস্বাভাবিকভাবে অনেক জায়গা থেকে এলে অ্যাডমিন রিপোর্টে দেখানো।

### ৩. ব্যবহারকারীর সুবিধা
9. **জবাবদিহি সঙ্গী (accountability partner)** — সুরক্ষা কমানোর অনুরোধে বন্ধু/অভিভাবকের অনুমোদন ইমেইলে।
10. **সাপ্তাহিক রিপোর্ট** — কত সময় বাঁচল, কত বার ব্লক হলো (শুধু PC-তে, গোপনীয়তা বজায় রেখে)।
11. **macOS সংস্করণ** — কোডের বড় অংশ তৈরি; Mac-এ পরীক্ষা ও Apple সই বাকি।
12. **মোবাইল (Android) অ্যাপ** — আলাদা প্রজেক্ট হিসেবে; একই Supabase অ্যাকাউন্ট/লাইসেন্স ব্যবহার করা যাবে।

### ৪. ব্যবসা ও সাপোর্ট
13. **অ্যাডমিন ড্যাশবোর্ড** — পেমেন্ট অনুমোদন, ডিভাইস সরানো, রিপোর্ট এক পাতায় (এখন Table Editor দিয়ে হয়)।
14. **স্বয়ংক্রিয় bKash যাচাই** (bKash Merchant/PGW API) — হাতে TrxID মেলানো লাগবে না।
15. **আরও ভাষায় ওয়েবসাইট** (অ্যাপ ইতিমধ্যে ৬ ভাষায়) — পাবলিক ওয়েবসাইট এখন শুধু US English।
