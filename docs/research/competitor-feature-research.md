## 1. Executive Summary

- **PC-তে সবচেয়ে শক্তিশালী তিনটি "self-control" blocker:** Cold Turkey, FocusMe, Freedom। এদের মধ্যে Cold Turkey-কে বাজারে সবচেয়ে "unbreakable" ধরা হয় (Locked block, Frozen Turkey, uninstall-কে block করা)।
- **সবচেয়ে শক্তিশালী tamper protection** আসলে আছে **Parental control** ও **Accountability** অ্যাপগুলোতে (Qustodio, Salfeld Child Control, Covenant Eyes, Accountable2You, Canopy, BlockerX)। এরা uninstall-এর জন্য password / partner-এর অনুমতি / partner-কে alert পাঠায়।
- **কেউই আসলে ১০০% bypass-proof নয়।** যার কাছে Administrator access আছে, সে Safe Mode, OS reinstall, বা অন্য drive থেকে boot করে যেকোনো blocker সরাতে পারে। তাই বাজারের সেরা অ্যাপগুলো "**defense in depth + commitment device + accountability**" — এই তিনটির মিশ্রণ ব্যবহার করে।
- **বাজারের সবচেয়ে বড় gap:** একটি অ্যাপ যেটা (ক) Cold Turkey-র মতো শক্তিশালী, (খ) Opal/one sec-এর মতো সুন্দর ও সহজ, (গ) Windows + macOS + Linux তিনটিতেই native, এবং (ঘ) partner-based uninstall protection দেয় — এমন একটিও নেই। এখানেই আমাদের সুযোগ।

## 4. Uninstall Protection — বিস্তারিত বিশ্লেষণ

### 4.1 বাজারে যে ৮টি মডেল দেখা যায়

| # | মডেল | উদাহরণ | ভালো দিক | দুর্বল দিক |
|---|---|---|---|---|
| 1 | **Locked session-এর সময় uninstall বন্ধ** | Cold Turkey, FocusMe, SelfControl | কেউ অনুমতি দিতে হয় না | Session না থাকলে সহজে uninstall |
| 2 | **Password দিয়ে uninstall** | Qustodio, Time Boss, FocusMe | সহজ | নিজে password রাখলে অর্থহীন |
| 3 | **Partner approval** (partner-এর ফোনে request যায়) | BlockerX, Canopy | অত্যন্ত কার্যকর | Partner লাগবে |
| 4 | **Partner-কে alert** (uninstall হলে partner জানে) | Covenant Eyes, Accountable2You, Ever Accountable | মানসিক বাধা শক্তিশালী | আটকায় না, শুধু জানায় |
| 5 | **Cooldown delay** (uninstall request → ২৪/৪৮ ঘণ্টা পর অনুমতি) | কিছু mobile app | ঝোঁকের মাথায় সিদ্ধান্ত ঠেকায় | ধৈর্যশীল user পার পায় |
| 6 | **Random text challenge** (৫০০+ অক্ষর random লেখা) | Cold Turkey, StayFocusd | partner ছাড়াই friction | কম কার্যকর |
| 7 | **OS-level account restriction** (user standard account, admin password অন্যের কাছে) | Microsoft Family Safety, Apple Screen Time | সবচেয়ে শক্তিশালী | Setup জটিল |
| 8 | **Self-defense** (process/file/registry সুরক্ষা) | Antivirus, Salfeld, Cold Turkey | চোখে পড়ে না, টেকনিক্যাল user-কেও আটকায় | ভুলভাবে করলে antivirus "malware" মনে করে |

### 4.2 আমাদের প্রস্তাবিত "Uninstall Protection" — ৪ স্তর (user নিজে বেছে নেবে)

| স্তর | নাম | কীভাবে uninstall সম্ভব |
|---|---|---|
| ০ | **Off** | যেকোনো সময় স্বাভাবিকভাবে |
| ১ | **Mindful** | ৬০ সেকেন্ড অপেক্ষা + "কেন?" প্রশ্ন + random text টাইপ |
| ২ | **Committed** | Uninstall request করার পর **২৪–৭২ ঘণ্টা cooldown** (user বেছে নেবে); এই সময়ে request বাতিল করা যায়, তাড়াহুড়া করা যায় না |
| ৩ | **Partner Lock** | Partner-এর ফোন/email-এ request যায়; partner approve করলেই uninstall। Partner ৭ দিন উত্তর না দিলে auto-approve (যাতে user কখনো চিরতরে আটকে না যায়) |
| ৪ | **Fortress** | স্তর ৩ + guided setup: user-এর account কে Standard বানানো, আলাদা admin account-এর password partner-এর কাছে, BIOS/UEFI password-এর গাইড |

> **নৈতিক নিয়ম:** সবসময় একটি **বৈধ বের হওয়ার পথ** থাকবে (cooldown বা partner timeout)। কাউকে চিরতরে আটকে রাখা অ্যাপ antivirus-এর কাছে "malware/PUA" হিসেবে চিহ্নিত হয় এবং আইনি ঝুঁকি তৈরি করে।


### 4.3 প্রযুক্তিগত নীতি (high-level)

সবচেয়ে শক্তিশালী এবং সবচেয়ে "পরিষ্কার" (antivirus-friendly) uninstall protection আসে **OS-এর নিজস্ব permission model** থেকে, কোনো গোপন কৌশল থেকে নয়। আমাদের নীতি:

- **OS-এর অনুমতি কাঠামো ব্যবহার করা:** অ্যাপের মূল অংশ admin-লেভেলের background service হিসেবে install হবে। যে user **Standard account**-এ আছেন, তিনি admin password ছাড়া service বন্ধ বা uninstall করতে পারবেন না। Windows Family Safety আর macOS Screen Time passcode ঠিক এই নীতিতেই কাজ করে।
- **Admin password partner-এর কাছে থাকবে (Fortress mode):** অ্যাপ user-কে ধাপে ধাপে গাইড করবে: একটা আলাদা admin account তৈরি করা, password partner-কে দেওয়া, নিজের account-কে Standard করা। এটাই সবচেয়ে কার্যকর পদ্ধতি, এবং পুরোপুরি স্বচ্ছ।
- **অ্যাপের নিজস্ব uninstaller-এ gate বসানো:** uninstaller নিজে cooldown, partner approval বা challenge চাইবে (৪.২-এর স্তরগুলো)।
- **Tamper হলে জানানো, লুকানো নয়:** service বন্ধ হলে, rule মুছে গেলে বা অ্যাপ সরানো হলে server-এ heartbeat বন্ধ হয়ে যাবে, আর partner-কে notification যাবে (Covenant Eyes / Accountable2You মডেল)। Offline থাকলে পরের বার online হলে জানানো হবে।
- **macOS:** Apple-এর অনুমোদিত **System Extension / Network Extension** আর **Configuration Profile** (removal password সহ) ব্যবহার করা হবে। Notarization বাধ্যতামূলক।
- **Linux:** systemd service, যেটা root-এ চলবে; user non-sudo account-এ থাকবেন (Fortress mode-এ)।
- **যা আমরা করব না:** rootkit-ধাঁচের লুকানো, অন্য security software-এ হস্তক্ষেপ, OS-এর security feature বন্ধ করা, অথবা কোনো বৈধ বের হওয়ার পথ না রাখা। এগুলো করলে antivirus অ্যাপটাকে malware হিসেবে ধরবে, store থেকে বাদ দেবে, এবং user-এর বিশ্বাসও নষ্ট হবে।

> Engineering পর্যায়ে প্রতিটি OS-এর জন্য আলাদা design document লিখতে হবে, এবং সেখানে Microsoft/Apple-এর developer guideline অনুযায়ী বিস্তারিত ঠিক করতে হবে।

## 5. "100% Effectiveness" — বাস্তবতা ও কৌশল

**সৎভাবে বলা দরকার:** কোনো সফটওয়্যারই ১০০% bypass-proof নয়। যার কাছে PC-র পূর্ণ admin access বা physical access আছে, তিনি শেষ পর্যন্ত OS reinstall করে যেকোনো অ্যাপ সরাতে পারবেন। বাজারের কোনো অ্যাপ (Cold Turkey-ও না) এটা আটকাতে পারে না।

তাই "100%"-এর বাস্তব সংজ্ঞা হবে: **"সাধারণ ও মাঝারি দক্ষ user-এর জন্য, ঝোঁকের মাথায় করা সব সাধারণ bypass বন্ধ; আর উন্নত bypass করলে partner অবশ্যই জানবেন।"**

এর জন্য ৩টি স্তর:

1. **Technical barrier:** network-level filter (শুধু browser extension নয়), app block, incognito/নতুন browser/VPN/DNS/clock bypass বন্ধ করা (৩.৪ দেখুন)।
2. **Commitment device:** Locked mode, cooldown, rule শুধু শক্ত করা যাবে (ঢিলা করা যাবে না), partner approval।
3. **Social accountability:** tamper করলে partner-কে alert। গবেষণা ও বাজারের অভিজ্ঞতা বলে, এটাই সবচেয়ে বড় মানসিক বাধা।

**পরিমাপ:** আমরা নিজেরা একটা "bypass test suite" বানাব: প্রতিটি release-এর আগে ৩.৪-এর তালিকার প্রতিটি bypass পরীক্ষা করা হবে, আর ফলাফল প্রকাশ করা হবে (স্বচ্ছতা = আন্তর্জাতিক মান)।

| **স্বচ্ছতা** | Install-এর সময় স্পষ্ট করে জানাতে হবে অ্যাপ কী করে। Tray icon সবসময় দৃশ্যমান থাকবে (Fortress mode-এও)। অন্যের PC-তে গোপনে নজরদারির (stalkerware) জন্য ব্যবহারের সুযোগ রাখা যাবে না। |
| **Accessibility** | Screen reader, keyboard navigation, high contrast (WCAG 2.2 AA)। |

## 7. User Friendliness — বাজার থেকে শিক্ষা

- **Cold Turkey-র সমস্যা:** শক্তিশালী, কিন্তু UI জটিল আর পুরনো ধাঁচের। নতুন user প্রায়ই ভুল করে নিজেকে আটকে ফেলেন।
- **Opal / one sec-এর সাফল্য:** সুন্দর animation, সহজ ভাষা, "শাস্তি" নয় বরং "সহায়তা"-র অনুভূতি।
- **Freedom-এর সাফল্য:** এক ক্লিকে সব ডিভাইসে session।

**আমাদের UX নীতি:**
1. প্রথম block ৬০ সেকেন্ডের মধ্যে শুরু করা যাবে (preset + ১ ক্লিক)।
2. Locked mode চালুর আগে স্পষ্ট summary দেখাবে: "এই session শেষ হবে রাত ১০টায়। এর আগে বন্ধ করা যাবে না। নিশ্চিত?"
3. **Safety net:** প্রথম ৭ দিন "Practice mode": Locked mode-এর সর্বোচ্চ সময় সীমিত থাকবে, যাতে কেউ ভুল করে বিপদে না পড়েন।
4. Block page-এ শুধু "Blocked" লেখা থাকবে না: user-এর নিজের লেখা লক্ষ্য, কত সময় বাকি, আর একটা বিকল্প কাজের পরামর্শ দেখাবে।
5. বাংলা + ইংরেজি দিয়ে শুরু, পরে আরও ভাষা।
