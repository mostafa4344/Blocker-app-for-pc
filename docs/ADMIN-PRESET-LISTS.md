# Admin গাইড: প্রস্তুত লিস্ট (Adult, Social media …) Supabase থেকে বদলানো

অ্যাপের "প্রস্তুত লিস্ট" (Adult content, জুয়া, সোশ্যাল মিডিয়া ইত্যাদি) এখন Supabase-এর
`preset_lists` টেবিল থেকে আসে। আপনি টেবিলে বদলালে **সব ইউজারের অ্যাপ ১৫ মিনিটের মধ্যে
নিজে থেকে আপডেট নেয়** — নতুন version বের করতে হয় না।

## একবারের সেটআপ
Supabase dashboard → **SQL Editor** → `supabase/migrations/20261025010000_preset_lists.sql`
পুরোটা paste করুন → **Run**। এতে টেবিল তৈরি হয় আর আজকের ১১টি লিস্ট বসে যায়।
(আবার চালালেও ক্ষতি নেই — আগের ডেটা মুছে যায় না।)

## লিস্ট বদলানো (যেমন Adult-এ নতুন সাইট যোগ)
1. Supabase dashboard → **Table Editor** → `preset_lists`
2. `adult` সারির **sites** ঘরে ক্লিক করুন — সাধারণ লেখা দেখাবে, যেমন
   `pornhub.com, xvideos.com, xnxx.com, …`
3. শেষে একটা কমা দিয়ে নতুন সাইট লিখে দিন (যেমন `, example-bad-site.com`), বা কোনোটা মুছে দিন → **Save**
4. ব্যস। ১৫ মিনিটের মধ্যে সব ইউজারের PC-তে ব্লক হয়ে যাবে।

**JSON, উদ্ধৃতিচিহ্ন (" ") বা ব্র্যাকেট [ ] লাগে না।** কমা বা নতুন লাইন দিয়ে আলাদা করলেই হয়
(sites-এ স্পেস দিয়েও চলে)। সার্ভার নিজে পরিষ্কার করে নেয়:
- `https://`, `http://`, `www.` আর শেষের `/` বাদ — পুরো লিংক পেস্ট করলেও চলবে
- বড় হাতের অক্ষর ছোট হয়ে যায় (sites ও keywords-এ)
- একই সাইট দুবার থাকলে একবার রাখে
- পুরনো JSON (`["a.com","b.com"]`) পেস্ট করলেও ঠিকমতো পড়ে

| ঘর | যেভাবে লিখবেন |
|---|---|
| `sites` | `facebook.com, instagram.com, youtube.com/shorts` |
| `apps` | `steam.exe, Discord, Epic Games Launcher` (নামের ভেতরের স্পেস থাকে, তাই কমা দিয়ে আলাদা করুন) |
| `keywords` | `porn, xxx, casino` |

| কলাম | মানে |
|---|---|
| `id` | **কখনো বদলাবেন না।** ইউজারের লিস্ট এই id দিয়েই যুক্ত থাকে। |
| `name_en` / `name_bn` | অ্যাপে দেখানো নাম। |
| `icon` | একটা emoji (যেমন 🔞)। |
| `sites` | ওয়েবসাইট — যেমন `site.com`, `*.site.com`, `youtube.com/shorts` |
| `keywords` | ঠিকানায় এই শব্দ থাকলে ব্লক (অন্তত ৩ অক্ষর) |
| `apps` | প্রোগ্রামের নাম — যেমন `steam.exe` |
| `always_on` | `true` = ২৪/৭ ব্লক। (অ্যাপ এটা শুধু চালু করে, কখনো বন্ধ করে না) |
| `enabled` | `false` = "প্রস্তুত লিস্ট যোগ করুন"-এ আর দেখাবে না (যাদের আছে তাদেরটা থাকবে) |
| `sort_order` | অ্যাপে কোন ক্রমে দেখাবে |

নতুন প্রস্তুত লিস্ট বানাতে নতুন সারি যোগ করুন: শুধু `id` (ছোট ইংরেজি, যেমন `drugs`),
`name_en` আর `sites` লিখলেই হয় — বাকিগুলো নিজে থেকে বসে।

## ইউজারের কী হয়
- আপনি যা **যোগ** করেন, তা সবার লিস্টে আসে।
- আপনি যা **সরান**, তা সবার লিস্ট থেকে সরে যায়।
- ইউজার **নিজে** যা যোগ করেছেন, তা সবসময় থেকে যায়।
- ইউজারকে সাইটের নাম দেখানো হয় না (Adult/জুয়া/ডেটিং-এর ক্ষেত্রে) — শুধু সংখ্যা।

## নিরাপত্তা (ভুল বা হ্যাক থেকে রক্ষা)
- ভুল ফরম্যাটের এন্ট্রি (স্পেস, লাইন ভাঙা, `#` ইত্যাদি) অ্যাপ বাদ দেয়।
- `*` (পুরো ইন্টারনেট ব্লক) সার্ভার থেকে কখনো গ্রহণ করা হয় না।
- একবারে কোনো লিস্টের **অর্ধেকের বেশি** মুছে ফেললে অ্যাপ ভুল ধরে নিয়ে সেই পরিবর্তন উপেক্ষা করে।
  তাই অনেক সাইট সরাতে চাইলে কয়েক ধাপে সরান।
- টেবিলটা শুধু আপনি (dashboard) পড়তে/লিখতে পারেন; অ্যাপ শুধু `get_presets()` দিয়ে পড়ে।
- ইন্টারনেট না থাকলে অ্যাপ শেষবার পাওয়া লিস্ট (বা নিজের ভেতরের লিস্ট) দিয়ে চলে।
