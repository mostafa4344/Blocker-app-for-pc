🌐 ওয়েবসাইটে কী আপলোড করবেন

HTL Content Guard PC · ধাপে ধাপে · শেষে Chrome এক্সটেনশন নিয়ে সহজ ব্যাখ্যা

১ফাইলগুলো কোথায় আছে

আপলোডের সব ফাইল একটা ফোল্ডারে গোছানো আছে:

dist\website-upload\content-guard-pc\

একসাথে একটা zip ফাইল হিসেবেও আছে: dist\website-upload.zip

ফাইলকী কাজ
index.htmlমূল পাতা: ডাউনলোড বোতাম আর ইনস্টলের নিয়ম
HTL-Content-Guard-PC-Setup.exeঅ্যাপটা নিজে (৩.৭ MB, ভার্সন 1.4.0)
install.htmlindex.html-এর মতো একই পাতা (পুরনো লিংকের জন্য)
purchase.htmlওয়েবসাইট থেকে Premium কেনা (বিকাশ/নগদ)
faq.htmlসাহায্য আর যোগাযোগ (WhatsApp / Gmail)
terms.html, privacy.html, refund.htmlআইনি পাতা। পেমেন্ট গেটওয়ে (Paddle) আর Chrome Web Store এগুলো চায়।
legal.cssপাতাগুলোর ডিজাইন। এটা বাদ দিলে পাতা এলোমেলো দেখাবে।

২ওয়েবসাইটে একটা ফোল্ডার বানান

আপনার হোস্টিংয়ের File Manager-এ (cPanel, Hostinger ইত্যাদি) public_html ফোল্ডারের ভেতরে নতুন একটা ফোল্ডার বানান। নাম দিন: content-guard-pc

এতে ঠিকানা হবে: https://আপনার-সাইট.com/content-guard-pc/

৩ফাইলগুলো আপলোড করুন

  1. content-guard-pc ফোল্ডারে ঢুকুন → Upload চাপুন।
  2. dist\website-upload\content-guard-pc\ ফোল্ডারের ৯টা ফাইলই বেছে নিয়ে আপলোড করুন।
    অথবা website-upload.zip আপলোড করে File Manager-এ Extract চাপুন।
  3. ফাইলের নাম কোনোভাবেই বদলাবেন না। ছোট-বড় হাতের অক্ষরও যেমন আছে তেমনই রাখতে হবে।
WordPress সাইট হলে: পাতাগুলো WordPress এডিটরে পেস্ট না করে File Manager দিয়েই ফোল্ডারে আপলোড করুন। এতে ডিজাইন ঠিক থাকবে।

৪পরীক্ষা করুন

  1. ব্রাউজারে খুলুন: https://আপনার-সাইট.com/content-guard-pc/
  2. ⬇ Download বোতাম চাপুন। Setup.exe ডাউনলোড শুরু হলে ঠিক আছে।
  3. উপরের Help / FAQ লিংকে গিয়ে WhatsApp লিংক চেপে দেখুন আপনার নম্বরে চ্যাট খোলে কিনা।
  4. পাতার ঠিকানাটা আমাকে দিন। আমি অ্যাপের ভেতরে "সাহায্য" আর "ওয়েবসাইট থেকে কিনুন" লিংক হিসেবে বসিয়ে দেব।

৫নতুন ভার্সন বের হলে

যারা আগে থেকে অ্যাপ ব্যবহার করছেন, তারা নিজে থেকেই আপডেট পান (Supabase থেকে)। ওয়েবসাইটে কিছু করতে হয় না।

শুধু নতুন ডাউনলোডকারীরা যাতে নতুন ভার্সন পায়, সেজন্য ওয়েবসাইটের HTL-Content-Guard-PC-Setup.exe ফাইলটা নতুন ফাইল দিয়ে বদলে দিন। নাম একই থাকবে।

🧩 Chrome Web Store-এ এক্সটেনশন আপলোড: আসলে কী হয়?

এক্সটেনশন আগে থেকেই আছে আর কাজ করছে। Chrome Web Store-এ ভার্সন 1.0.0 লাইভ। অ্যাপ ইনস্টল হলে Chrome আর Edge-এ এক্সটেনশনটা নিজে থেকে বসে যায়, আর লক হয়ে থাকে যাতে কেউ মুছতে না পারে।

আমি নতুন ভার্সন 1.1.0 বানিয়েছি। Store-এ আপলোড করলে সব ইউজারের এক্সটেনশন Chrome নিজেই ১–২ দিনের মধ্যে আপডেট করে দেবে।

সাইট ব্লক, Shorts/Reels ব্লক, SafeSearch✔ চলবে✔ চলবে
ব্লক পাতার ভাষাবাংলা + English+ আরবি, উর্দু, ইন্দোনেশিয়ান, তুর্কি
ব্লক পাতায় "সবসময় ব্লক" কারণ দেখানোদেখায় না✔ দেখায়
কোন ব্রাউজারে (Chrome/Edge/Brave) সুরক্ষা চালু আছে, তা আলাদা করে জানামোটামুটি✔ নির্ভুল

সারকথা: আপলোড না করলেও অ্যাপ কাজ করবে, কিছু ভাঙবে না। তবে নতুন সুবিধাগুলো পেতে আপলোড করা ভালো। এতে ৫ মিনিট লাগে।

  1. chrome.google.com/webstore/devconsole খুলুন (যে Gmail দিয়ে আগে আপলোড করেছিলেন, সেটা দিয়ে)।
  2. HTL Content Guard PC এক্সটেনশনে ক্লিক করুন → বাঁ দিকে Package → Upload new package।
  3. এই ফাইলটা দিন: dist\content-guard-extension.zip
  4. Submit for review চাপুন। Google ১–৩ দিনের মধ্যে পর্যালোচনা শেষ করবে, তারপর সবার কাছে নিজে থেকে পৌঁছে যাবে।
নতুন এক্সটেনশন বানাবেন না। আগেরটাতেই "Upload new package" দিন। নতুন বানালে আইডি বদলে যাবে, আর অ্যাপ সেটাকে চিনবে না।
